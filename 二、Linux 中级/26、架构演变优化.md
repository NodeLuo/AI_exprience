3、模板机优化步骤

```bash

	a.右键虚拟机 -> 点击设置 -> 点击添加 -> 点击网络适配器
	b.选中新添加的网络适配器 -> 将NAT模式换成LAN区段 -> 点击LAN区段 -> 添加全局LAN区段 -> 输入172.16.1.0/24 -> 点击确定 -> 在LAN区段下点击选择刚才添加的LAN区段
```
