3、模板机优化步骤

```bash
1、添加第二块网卡

	a.右键虚拟机 -> 点击设置 -> 点击添加 -> 点击网络适配器
	b.选中新添加的网络适配器 -> 将NAT模式换成LAN区段 -> 点击LAN区段 -> 添加全局LAN区段 -> 输入172.16.1.0/24 -> 点击确定 -> 在LAN区段下点击选择刚才添加的LAN区段
```

4、修改默认的yum仓库为阿里云

```bash
1、访问阿里云页面
	[阿里巴巴开源镜像站-OPSX镜像站-阿里云开发者社区](https://developer.aliyun.com/mirror/)

2、点击CentOS

3、备份默认仓库
	[root@breadbomb network-scripts]# mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.bak
```

7、关闭NetworkManger、firewalld防火墙

```bash
[root@breadbomb ~]# systemctl stop NetworkManager firewalld
[root@breadbomb ~]# systemctl disable NetworkManager firewalld

#查看是否关闭
systemctl status NetworkManager
systemctl status firewalld
```

8、关闭selinux防火墙

```bash
	1、查看selinux状态
		getenforce
	
	2、临时设置selinux状态
		setenforce 0
	
	示例：
		[root@breadbomb ~]# getenforce
		Enforcing
		[root@breadbomb ~]# setenforce 0
		[root@breadbomb ~]# getenforce
		Permissive
	
	3、永久关闭selinux
		vim /etc/selinux/config
		或
		sed -i '7c SELINUX=disabled' /etc/selinux/config
		
	4、查看是否关闭
		[root@breadbomb ~]# cat /etc/selinux/config
		
		# This file controls the state of SELinux on the system.
		# SELINUX= can take one of these three values:
		#     enforcing - SELinux security policy is enforced.
		#     permissive - SELinux prints warnings instead of enforcing.
		#     disabled - No SELinux policy is loaded.
		SELINUX=disabled
		# SELINUXTYPE= can take one of three values:
		#     targeted - Targeted processes are protected,
		#     minimum - Modification of targeted policy. Only selected processes are protected. 
		#     mls - Multi Level Security protection.
		SELINUXTYPE=targeted 


```
